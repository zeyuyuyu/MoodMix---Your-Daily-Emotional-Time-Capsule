# MoodMix
A beautiful, engaging web app that lets users track their daily mood through color, music, and short reflections. Users pick a color that matches their mood, select from curated music snippets, and write a brief thought. The app creates a stunning visual timeline of emotional moments that can be shared or kept private. Features daily streaks, weekly patterns, and monthly emotional 'artwork' generated from user's moods.

Key Features:
- Interactive color wheel mood selector
- Curated music mood snippets
- Beautiful animated transitions
- Daily streaks and rewards
- Shareable mood patterns
- Progressive Web App support
